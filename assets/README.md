# Profile assets

The banner, greeting, dividers and project cards are custom SVG assets for this profile.

Technology icons are from [Skill Icons](https://skillicons.dev/), stored locally so the README does not depend on an icon service at viewing time.

The animated Octocat is from the [public GitHub image used in the reference profile](https://user-images.githubusercontent.com/5713670/87202985-820dcb80-c2b6-11ea-9f56-7ec461c497c3.gif). Octocat is a GitHub character.

`github-activity.svg` is generated by `scripts/update-stats.mjs`. It counts public, non-fork repositories with content, excluding this profile repository. Language counts use each repository's primary language. Demo links refer to the three linked demo projects and do not measure uptime.
